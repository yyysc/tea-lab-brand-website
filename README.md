# TEA LAB 茶饮品牌官网

TEA LAB 是一个面向年轻消费群体设计的现代茶饮品牌官网前端项目，主要用于展示品牌视觉设计、页面布局与前端交互效果。

项目包含首页、品牌故事页和加盟合作页，并实现了中英文切换、响应式布局、轮播展示、滚动动画以及移动端菜单等功能，可作为前端开发与网页设计方向的作品集项目。

## 项目功能

- 响应式网页布局，适配桌面端与移动端
- 中英文双语切换
- Swiper 产品轮播展示
- AOS 页面滚动动画
- 品牌故事与品牌理念展示
- 热门饮品展示
- 门店信息展示
- 加盟合作介绍与加盟流程
- 联系表单与加盟申请表单界面
- 移动端侧边菜单
- 平滑滚动与页面交互动效

## 技术栈

- HTML5
- CSS3
- JavaScript
- Swiper
- AOS（Animate On Scroll）

## 页面组成

- `index.html`：网站首页
- `brand.html`：品牌故事页面
- `join.html`：加盟合作页面

## 主要实现内容

### 首页

首页主要包含：

- 品牌主视觉 Banner
- 热门饮品轮播展示
- 品牌介绍
- 品牌数据展示
- 门店展示
- 联系表单
- 页脚导航

### 品牌页面

品牌页面主要展示：

- 品牌文化
- 品牌故事
- 品牌理念
- Premium / Design / Lifestyle 三个品牌价值方向

### 加盟页面

加盟页面主要包含：

- 加盟品牌介绍
- 合作伙伴要求
- 品牌支持体系
- 加盟流程
- 加盟申请表单

## 交互设计

项目使用 JavaScript 实现了多种页面交互效果，包括：

- Swiper 自动轮播
- AOS 滚动动画
- 页面滚动时导航栏阴影变化
- 移动端菜单展开与关闭
- 中英文内容动态切换
